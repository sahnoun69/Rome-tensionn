ROME — Métiers en tension (PWA)

Fichiers :
- index.html : interface de recherche
- manifest.json : installation sur Android
- sw.js : cache hors ligne
- data.js : données locales (à remplir avec le jeu de données officiel)
- icons/ : icônes

IMPORTANT :
Ce paquet est un modèle fonctionnel d'interface, mais il ne contient PAS encore la liste officielle complète.
Il ne faut pas l'utiliser pour tirer des conclusions sur un code ROME tant que data.js n'a pas été rempli avec les correspondances extraites des annexes I et II de l'arrêté français du 21 mai 2025.

Pour publier gratuitement : créer un dépôt GitHub, téléverser le contenu de ce dossier, puis Settings > Pages > Deploy from a branch > main / root. Après publication, ouvrir le lien HTTPS dans Chrome Android et choisir Installer l'application / Ajouter à l'écran d'accueil.
